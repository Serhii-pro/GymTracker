🏋️‍♂️ GYM Tracker

GYM Tracker is a modern, dark-themed web application designed to plan weekly workouts, log exercises and working weights, and track strength progression over time.

🔗 Live Demo: https://serhii-pro.github.io/GymTracker/

📌 Кроткое описание для GitHub (секция «About»)

EN: Modern weekly workout planner and strength progression tracker with interactive analytics and a dark neon UI.

RU: Современный трекер тренировок с недельным планировщиком, аналитикой силового прогресса и удобным темным интерфейсом.

✨ Key Features / Основные возможности

🇬🇧 English

📅 Weekly Schedule & Navigation: Browse through training weeks (Week 1–52) with quick navigation (Previous, Next, and Today) and clear date ranges.

💪 Structured Workout & Rest Days: Visual 7-day layout (Monday – Sunday) separating active Workout days (Monday, Wednesday, Friday, Saturday) from Recovery / Rest Days (Tuesday, Thursday, Sunday).

📝 Exercise & Weight Logging: Easily add exercises to any workout day, track completed sets/exercises via visual progress indicators, and record working weights.

📈 Analytics & Exercise Progression: Dedicated Stats dashboard displaying weekly max weight progression charts for all logged exercises, automatically sorted from the most recently updated.

🔄 Quick Week Reset: One-click Reset Week action to clear current weekly data when starting fresh.

🌙 Sleek Dark Neon UI: High-contrast dark interface with neon green accents, optimized for visibility at the gym on both desktop and mobile screens.

🇷🇺 Русский

📅 Недельный планировщик: Удобное переключение между неделями года с отображением дат и быстрым переходом к текущей неделе по кнопке Today.

💪 Разделение на тренировки и отдых: Наглядная сетка на 7 дней недели с четким разделением на тренировочные дни (Workout) и дни восстановления (Rest Day / Recovery Day).

📝 Логирование упражнений: Быстрое добавление упражнений (+ Add Exercise), индикаторы выполнения и фиксация рабочих весов.

📈 Аналитика и прогрессия весов: Раздел Stats («Analytics & Progress») с графиками максимального рабочего веса по неделям (Max weight logged per week), отсортированными от самых недавно обновленных упражнений.

🔄 Управление неделей: Кнопка Reset Week для быстрого сброса прогресса текущей недели.

🌙 Темный неоновый интерфейс: Контрастный темный дизайн, удобный для использования в тренажерном зале как с компьютера, так и со смартфона.

🚀 Getting Started / Запуск проекта локально

Clone the repository / Клонируйте репозиторий:

git clone https://github.com/serhii-pro/GymTracker.git
cd GymTracker


Install dependencies / Установите зависимости:

npm install


Run the development server / Запустите локальный сервер:

npm run dev


Build for production / Сборка проекта:

npm run build


📱 Using on Mobile / Использование на телефоне

You can install GYM Tracker directly onto your smartphone's home screen:

Open https://serhii-pro.github.io/GymTracker/ in Safari (iOS) or Chrome (Android).

Tap Share → Add to Home Screen (iOS) or Menu (⋮) → Add to Home screen / Install app (Android).
